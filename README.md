# Кинематографический язык

[Открыть справочник](https://somedayfounder.github.io/cinema-guide/)

537 приёмов в 27 разделах, 373 локальных видеопримера. Компактные карточки открывают подробный разбор, галерею, упражнения и ссылки на похожие приёмы. В галерее есть стрелки, счётчик, миниатюры и переключение клавишами ←/→. Кадры можно открыть крупнее и листать отдельно. Доступны поиск, выбор нескольких разделов, фильтр по типу примера и избранное в браузере.

Первый кадр виден сразу. Наведение запускает беззвучный ролик. Клик или касание открывают разбор с плеером и управлением звуком. При включённом сокращении анимации автоматическое проигрывание отключено.

Источники, авторы и указанные ими лицензии доступны в разборах. ИИ-демонстрации из опубликованных каталогов отмечены отдельно. Права на сторонние материалы принадлежат их правообладателям. Упражнения составлены для справочника; фильмы в разделе «Где искать» взяты из исходного гайда.

Для просмотра без интернета скачайте репозиторий или архив целиком и откройте index.html. Все медиа и шрифты находятся внутри. Избранное хранится в localStorage; его доступность при открытии локального файла зависит от браузера. Ссылки на источники требуют интернета.
