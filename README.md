# Кинематографический язык

Справочник приёмов кино с поиском и видеопримерами.

[Открыть гайд](https://somedayfounder.github.io/cinema-guide/)

Первый кадр виден сразу. Наведение запускает беззвучную анимацию. Клик или касание открывают просмотр с управлением и оригинальным звуком, если он есть.

Источники, авторы и указанные ими лицензии доступны в карточках. Подписанные ИИ-демонстрации взяты из опубликованных каталогов. Права на сторонние фильмы и материалы принадлежат их правообладателям. Условия открытых материалов указаны по ссылкам под соответствующими примерами.

Для локального просмотра скачайте репозиторий целиком и откройте index.html.
