# Кинематографический язык

[Открыть справочник](https://somedayfounder.github.io/cinema-guide/)

537 приёмов в 27 разделах, 373 локальных видеопримера. Компактные карточки открывают подробный разбор, галерею и пояснения к отличиям от похожих приёмов. В галерее есть стрелки, счётчик, миниатюры и переключение клавишами ←/→. Кадры можно открыть крупнее и листать отдельно. Разделы идут подряд на одной странице. Слева закреплено меню с якорными ссылками и подсветкой текущего раздела; на телефоне меню сворачивается. Все разделы доступны сразу. Доступны общий поиск, фильтр по типу примера, порядок карточек внутри раздела и избранное в браузере.

Для 191 приёма добавлены отдельные наблюдаемые признаки и пояснения к действию в сцене. 92 пары похожих приёмов снабжены объяснением различий. Во всех 27 разделах есть подсказки к просмотру с учётом типа материала. Комментарий к выбранному примеру находится рядом с медиа и меняется при листании; для dolly zoom добавлена схема компенсации масштаба. Упражнения и блок идей для коротких роликов удалены.

В 249 карточках есть дополнительные 242 кадра и 140 кинофрагментов. Галереи с несколькими материалами есть у 423 карточек; у 112 пока один пример. Для «Ритма дыхания» и «Визуальной дуги для запоя» точный самостоятельный визуальный пример пока не подтверждён.

Первый кадр виден сразу. Наведение запускает беззвучный ролик. Клик или касание открывают разбор с плеером и управлением звуком. При включённом сокращении анимации автоматическое проигрывание отключено.

Источники, авторы и указанные ими лицензии доступны в разборах. ИИ-демонстрации из опубликованных каталогов отмечены отдельно. Права на сторонние материалы принадлежат их правообладателям. Признаки, пояснения и сравнения составлены для справочника; фильмы в разделе «Фильмы для дальнейшего разбора» взяты из исходного гайда.

Для просмотра без интернета скачайте репозиторий или архив целиком и откройте index.html. Все медиа и шрифты находятся внутри. Избранное хранится в localStorage; его доступность при открытии локального файла зависит от браузера. Ссылки на источники требуют интернета.
